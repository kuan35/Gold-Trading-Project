# 公開逐筆案例檢索與 DEMO 唯讀報價驗證

日期：2026-10-19。資料範圍由使用者在對話中明確指定為「公開原始逐筆資料」。本次實際公開的是產品已整理的 `trader-cases.json` 原樣逐筆檔，而非 221 份原始對帳單。逐筆時間、進出場價格、手數、損益與群組內操作序列都在檔案中，公開後可被下載及保留。帳戶號碼、原始檔名、憑證、其他私人側檔不在發布白名單。

## 資料與流程

| 項目 | 數量／定義 |
| --- | --- |
| 整理後逐筆案例 | 11,902；不等於去重後的決策數 |
| 可用進場前參考盤面 | 10,887；完整三週期 6,542、五分鐘限定 4,345 |
| 無可用參考盤面 | 1,015；保留於原樣資料檔但不進盤面排名 |

公開檢索僅篩 BUY／SELL、查詢前已成熟與參考盤面資料層；比較進場前 60 根已收五分鐘 K 線的首棒百分比收盤路徑與各週期指標，以池內相對排名找近鄰，在前 15 個不同操作群內將三段型態完全相同者提前。手數、首筆／加倉和事後損益不參與排名。展示逐筆結果、歷史結果分布、固定格式盤面描述及指標差；案例詳情可畫公開索引中的 60 棒百分比收盤路徑，明示它不是逐棒 OHLC。很長的操作群序列預設只顯示前 12 筆，可自行展開全部。畫面明確標示「合成查詢／真實案例」、參考對齊 `PROJECT_REFERENCE`、券商原始時鐘 `UNKNOWN`。足夠相似的絕對拒絕門檻尚未經人工相關性資料校準，有案例也標 `UNCALIBRATED`。

本機 Python 與公開 TypeScript 實作在 8 組固定回放查詢（四時點、雙方向）的候選數及各層前五案例 ID 完全一致。這驗證實作同義，不是排名品質或準確率。2021–2023 的 21 組新期間匿名封包、300 個配對尚無獨立人工相關性分數（0 筆），因此目前不能報相似度準確率或宣稱某個案例已「足夠相似」。未來後端接入真實當下行情時，須建立同一版已收 K 線 profile，與合成回放結果分開標示，再做同池盲評與留出日期門檻校準。

## 報價邊界

本機 DEMO 帳戶已用 cTrader Open API 的唯讀商品清單及 spot 訂閱驗證 XAUUSD 報價。`GET /api/broker/quote` 由子行程取得單次 BID／ASK 快照，回傳來源時間、年齡與狀態，不回傳憑證或帳戶識別碼；未設定時價格為空。前端「即時看盤」每約 20 秒刷新。它與 TradingView 的 OANDA 圖表是兩個來源，不參與回放、檢索、草稿風險或券商成交。公開 Pages 仍只有 TradingView 外部圖，沒有 cTrader DEMO 金鑰或報價 API。

## 重跑與發布檢查

在 `product/` 執行 `python -m research.audit_hybrid_library` 查看匿名覆蓋統計；`python -m research.export_public_history --output frontend/public/data` 重建精確白名單的三個靜態檔。發布前執行前後端目標測試、前端 `npm test` 與 `npm run build:pages`，用私人 parity 工具核對 Python／TypeScript 排名，檢查 Git 暫存清單及憑證樣式，並用 `private/time_completion_20261013/integrity_check.py` 確認原件與正式輸入未變。原始對帳單、私人側檔、`.env.ctrader`、token 與帳戶資訊一律不加入公開 Git。
