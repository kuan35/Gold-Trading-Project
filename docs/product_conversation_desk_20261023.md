## 畫面與操作

- 左側導覽：交易對話、即時看盤、歷史回放；完成的對話可重新閱讀。
- 頁首：原生 XAUUSD BID／ASK、行情時間、DEMO 帳戶狀態與明暗切換。未就緒或報價過期時隱去舊價格，不補日漲跌或成交量。
- 中央：固定上下界且可調高／寬的聊天；輸入區在聊天紀錄之外。回覆優先顯示短摘要、同向與相反的已收棒趨勢、最相近一組案例的原報表結果；詳細指標、量能與歷史分布可展開。沒有假相似百分比或未校準勝率。
- 點看圖：同頁展開該回答原快照的五分／十五分／一小時圖；案例可看五分及一小時對照。頁首 tick 持續更新，圖明示為固定分析快照。
- 右側委託與聊天內表單共用欄位。數值修改回覆前後差異，方向改變才重新分析。問「如果做空」先討論，仍須按套用才改草稿。檢查後沿用原有版本、期限、防重送與人工確認；送出回報未知時仍鎖住。
- 底部：券商 DEMO 持倉、待成交與下單紀錄。未連線不顯示為零筆；過期 PnL 與依賴 PnL 的淨值不當最新值顯示。平倉沿用原有檢查與確認。
- 窄螢幕改上方導覽、橫向歷史紀錄與可展開委託；聊天仍有自己的固定高度。

## 對話紀錄界線

此輪提供瀏覽器文字紀錄，不是後端多用戶會話。最多十二段對話、每段二十輪；單輪問題與摘要有長度上限。只序列化問題、回答文字和時間，移除非白名單物件並遮蔽常見憑證字串。不可把這個遮蔽當成可輸入金鑰的功能。

開啟舊紀錄只呈現標示時間的文字，不還原 API 快照、可套用提案、草稿、確認 key 或可送單按鈕。目前共用草稿保留不變；重新整理後草稿清空。分析／檢查／未知送單鎖定期間不能切換對話。畸形或新版儲存格式不覆寫原值；儲存滿額則提示本頁暫存。
