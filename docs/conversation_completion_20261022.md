# 聊天案例明細與未知回報保護

2026-10-22，本機補全，未部署公開站。

## 本輪完成

- 有符合案例時，先顯示可見初始／加倉脈絡，並可展開「同群可見操作」。其他案例的比較區也有相同入口。
- 明細呈現代表單筆進出價及原報表結果，再列群內可見操作的方向、手數、進出價、逐筆結果與來源序號。資料不足、缺漏、截斷、記載筆數衝突及同時點順序未知都分開標示；最多展示100列，只有整頁捲動。
- 每列幣別只取本列資料。即使代表單筆明示USD，群內序列沒有幣別仍顯示未載；沒有加總成群組淨損益。
- 操作資料與原分析同時凍結。開明細不抓新行情、不重排、不另讀新案例；過期就請重新提問。這些原值存在本機快照獨立欄位，不加入模型facts。
- 後端也檢查耐久提交日誌：未知或不明回報不能靠新草稿、另一分頁或重啟程序繞過。舊草稿同一防重送key仍讀原結果；已知接受與部分成交不當作未知或已成交。畸形status保留UNKNOWN，不因格式錯誤變成可重送。

## 使用方式

在本機聊天說出方向，出現通過規則的案例後，按「同群可見操作」；「看 K 線對照」仍讀原分析圖表。若此時沒有案例通過，畫面照實顯示無符合，不為展示明細而塞入未過門檻的交易。

遇到「此帳戶已有送單回報待核對」時，先開持倉與紀錄及cTrader核對，不能用另一張草稿重送。新保護不包含人工猜測／自動清除UNKNOWN；只有可辨識的券商回報才能更新結果。未知紀錄缺帳戶歸屬時保守處理，明確不同帳戶則隔離。
