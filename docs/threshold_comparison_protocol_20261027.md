# 門檻比較：執行前固定協定

2026-10-27。使用者要求實做門檻比較；本輪是離線敏感度與數值取捨研究，不修改正式檢索、來源時間模型、API或網站，不送單、不呼叫外部模型、不訓練模型。

## 樣本與方法

沿用10/23已固定的30個不同日期查詢（2024–2025），前20為開發描述組，後10為保留描述組，分開報告。這些日期先前已產出過基線結果，不是本輪新取得、全然未見的獨立測試集。不按本輪輸出或損益換日期。讀原selection及輸入SHA；不重寫原盲評材料或評分。

沿用ContextIndex的同向／成熟／完整／不重疊篩選與事件規則，整池計算相同pair_metrics；每組門檻皆使用原evaluate_rows排序／群與時點去重。以原30次中檔輸出逐筆核對。檢查嚴通過集合包含於中、中包含於寬；輸出逐例斷言時間／方向／排除自身群。差距及彙總不得讀取profit。

## 固定13組；跑完不追加或改值

1. 原嚴／中／寬：(.15,.30,.06,1.5)、(.25,.50,.10,2)、(.40,.80,.16,3)。前三項是百分點，最後是ATR%倍率。
2. 以中檔為基線，一次只改一項：五分.20／.30，小時.40／.60，末段.08／.12，波動1.5／3，共8組。
3. 基線四項較容忍下限的距離同步縮／放10%，路徑乘.9／1.1，波動用1+(2-1)×.9／1.1，即1.9／2.1，共2組。

固定0.1事件緩衝、0.5末段中性帶、5m60／1h20／最後6棒／前20棒、TR14；本輪不聲稱已比較這些固定值的優劣。

## 指標與公平比較

- 全查詢分母：有結果次數／查詢總數，至少五例次數，全去重匹配數中位數；資料不足／不明／無合格池／全未過分開。
- 每個方案對中檔：共同有結果查詢數、僅方案有／僅中檔有、top1案例及群一致率、top5群Jaccard。共同沒有結果不算一致率；Jaccard在任一清單空時回null，不把雙空當完美穩定。
- 數值取捨只在該方案與中檔共同有結果的同一查詢上，分別報第一名的5m／1h／末段差距及波動倍率的中位數。這些就是檢索輸入，只能作內部取捨診斷，不能作準確率。
- 用固定中檔尺度算最大標準化差，避免寬門檻因分母變大看似變好；此值也不代表人評品質。
- +/−10%是局部擾動診斷，只描述是否換案例／翻轉有無結果。其餘單項組是較大步長敏感度，兩者不混稱。
- 輸出可重跑JSON／CSV及三張總覽圖。另取按時間前六個嚴／中／寬第一名或有無結果不同的查詢，產生K線診斷對照；挑圖是展示差異，非盲評或優劣樣本。

解釋補充（本輪程式審查確認，未改實驗）：原evaluate_rows也用各門檻作排序的標準化分母。故單項改動同時改准入與排名尺度，這是現有產品的參數敏感度，不是已隔離純篩選效果的因果實驗。固定中檔分數只供診斷，沒有固定各方案的實際排序。
