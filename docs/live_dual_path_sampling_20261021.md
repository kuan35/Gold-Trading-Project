# 雙週期路徑＋前高低狀態：即時試作與10時點抽樣

使用者已要求實作新方法並看10個盤面結果，並選擇「券商最新取得行情中的最近10個不同五分鐘收盤時點」。本輪不是等待45分鐘持續收集；保留原始擷取時間，九個較早時點是最近行情回看，不冒充當時即時記錄。

## 固定試作規則

- 方法ID `dual_path_structure_v1`。只用已收5分60根收盤路徑、1h20根收盤路徑，以及末5分棒對先前20棒高低狀態。路徑首棒歸零的百分比RMSE；前高低相同優先，再按兩軸較差分位、分位和、ID。群／盤面時點去重。無DTW、文字向量、12指標排序或人工挑權重。波動倍率僅展示。
- 把原先離線規則移入無NumPy依賴的後端模組，與離線算法核對排名。索引只用完整雙週期參考盤面；仍檢查已成熟、同方向、進場前窗口不重疊。原始時鐘UNKNOWN、PROJECT_REFERENCE及UNCALIBRATED保留。
- 本機 `/api/broker/cases` 可選新舊方法；DEMO草稿使用所選方法。公開Pages與回放仍保留原方法；本輪不推送、不送任何委託。新盤面整理只要求5分與1h，不再因15分缺資料而拒絕新方法。

## 抽樣與圖表

- 保存從本機DEMO唯讀API取得的5分／1h與商品交易時段快照，移除帳戶、token、secret、帳戶持倉等資訊。
- 取來源時間以前最近10個已收5分棒的收盤時點，按時間由舊至新編Q01–Q10；固定BUY／SELL交錯各5個，方向為測試輸入，不是系統預測。每時點只讀當時已收棒；不以後續結果挑盤面或案例。
- 每時點保存前五名與第一名，畫查詢與第一名各自的5分60／1h20 K線（每頁四圖、同欄同尺度、首收歸零），明列日期／方向／狀態、兩距離、波動倍率與相同／不同處。前高低虛線只覆蓋所用先前20棒範圍。
- 另出10組縮圖總覽、10頁合併PDF、逐時點JSON、CSV、來源／輸入／程式SHA-256及獨立核對。全留 `product/private/live_dual_path_samples_20261021/`，不公開。
- 近期十個盤面彼此重疊、一小時背景可能相同，不能當10個獨立情境或準確率測試。若同一歷史案例多次第一名，據實保留，不為多樣性改排名。

## 驗證

新模組先測時序／來源／缺棒、排名與離線算法一致、結構優先、成熟／不同群／重疊窗口、去重、無結果與不使用手數／盈虧；API和前端契約同步。實際GET驗證行情與新方法，對10時點全部重跑與逐對核對。沒有下單或模型訓練。
