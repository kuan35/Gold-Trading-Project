# 歷史聊天保存修正

原保存只抽前兩段、每則1800字、每串20則、12串，較早文字被靜默截掉；重整後
又建立空白thread，因此使用者容易以為沒有保存。這些限制屬舊版本行為，已移除。

目前保存範圍：完整問題、全部回答段落、可見提示／錯誤、模型名稱、支持／相反
訊號、案例條件與差異、代表單筆結果、量比、歷史分布、後續5／30／60分鐘及
原草稿情境數值摘要、逐項文字依據。問題送出但尚未回答也會留下未完成提示。
歷史文字較長時可展開，不用把所有數據擠在第一眼。

仍使用同瀏覽器localStorage及既有gold-desk-conversations-v1 key；內容schema
升至version2，讀取version1自動遷移，保留名稱／改名／刪除，不接受未知版本或
損壞內容後覆寫。記住activeId，重整時回到原對話；明確新增空白串也會保留。
不再按串數／則數／回答字數剪掉資料。整份4,000,000字元為保護上限，實際瀏覽器
quota可能先到；無法儲存時明示警告，保留先前磁碟紀錄，不假稱已保存、不自動
刪掉舊串。若在警告後關閉頁面，新變更仍可能遺失。

只保存文字與計算摘要，不儲存可執行委託／確認key、帳戶憑證或可重送動作。
原快照K線、按需載入的操作明細不是離線圖像備份，重新分析仍需有效資料服務；
重新開啟不會重建原單、不自動問模型。LLM上下文依舊只送近6則的去識別摘要，
不能把完整儲存和無限模型記憶混為一談。

同一台電腦也需同瀏覽器、同origin（固定http://127.0.0.1:8765/）。localhost、
不同埠、不同瀏覽器、無痕模式與清除網站資料均不共享紀錄。組員安裝相同程式，
不會因此取得作者的聊天紀錄。已被舊版剪掉且頁面已關閉的內容無法回復。

驗證涵蓋完整第三段、長文字、15串×27則、未完成／失敗、v1遷移、異常版本、
quota、重新載入原串、續聊、改名、刪除、歷史不可執行；未消耗模型或送交易。
