# 操作與盤面分項案例比較

目的：下單前提供條件相近的歷史操作與可追溯差異，包含首筆和加倉；沒有足夠案例時誠實說明，仍分析當下已收盤行情。不是預測本筆勝率，不要求交易員大量逐單標註。

## 比較流程

1. 同方向、同操作類型、查詢前已成熟。原本的保守成熟時間不變；每候選操作群最多一例，不能視為獨立決策。
2. 操作距離保留原公式與0.65門檻。首筆只有方向、可見首筆和手數，明示辨識力有限；加倉另比既有單數、加單占原部位倍數和距均價百分比。
3. 本次行情完整、且同方向／類型的已成熟歷史案例存在可用盤面時，採操作＋盤面模式，只保留具盤面證據的案例；兩個距離門檻各自通過，再以操作40%、盤面60%排序。
4. 若有可用盤面案例但沒有任何案例同時通過門檻，回傳零案例，不退回較弱匹配硬湊。若根本沒有核實盤面資料，保留操作參考並明示「盤面尚無法比較」。
5. 完整池形成後才按盈虧分組：各取最近3個獲利及虧損，缺額由排名補滿，另提供各類前6例。分組不改完整池、排序或距離。

## 盤面特徵與設定

| 特徵 | 權重 | 差異刻度 |
|---|---:|---|
| 5分價格距MA20／ATR | 0.15 | 2 ATR |
| 15分價格距MA20／ATR | 0.15 | 2 ATR |
| 1小時價格距MA20／ATR | 0.10 | 2 ATR |
| 5分MA20近5根平均斜率／ATR | 0.10 | 1 ATR／根 |
| 5分最近60根高低區間內位置 | 0.10 | 區間長度1 |
| 距最近候選支撐／ATR | 0.10 | 2 ATR |
| 距最近候選壓力／ATR | 0.10 | 2 ATR |
| 5分ATR占價格百分比 | 0.20 | 波動倍數的log2差 |

盤面距離上限0.40；未知欄位距離成本1，不刪權重。可比較欄位權重至少80%，三個週期的價格距MA20都必須存在。1小時價格距均線超過0.5 ATR且兩案例方向相反時，不互配；ATR百分比相差超過2倍時排除。

上下文固定每週期最多120根，5分／15分至少60根、1小時至少20根；只使用完整已收K棒。近期缺口超過3個該週期、末根過期或OHLC不合法則資料不足。ATR用Wilder14；因固定上下文，可能與畫面使用更長歷史起算的ATR略異。支撐壓力由左右各2根已確認轉折產生，並非交易員畫線，也不代表價位有效性認證。沒有用成交量或新聞：來源定義與跨來源可比性尚未滿足。

所有價格與倍數用Decimal；只有無單位距離轉float。不同年代金價等比例變動不改特徵距離。此方法是盤面條件比較，尚未實作逐根K線形狀識別，也未驗證能改善交易結果。

## 時間證據與側檔

`scripts/prepare_market_similarity.py` 只讀原始案例／行情與時間查核清單。每案例必須同時具有：

- `timezone_status: CONFIRMED`
- `market_time_status: CONFIRMED`（行情來源時鐘也已核實）
- `can_use_for_market_similarity: true`
- `open_utc`：明確帶時區的實際進場時間，不能使用候選欄位
- `evidence_ref`：相對product/private的可讀證據檔
- `reviewed_by`：核對者或可追溯查核程序

不會自動把價格候選升級成確認。結果寫`private/case_market_profiles.json`，綁定案例、行情、清單和證據檔SHA；任一輸入改變即停用盤面側檔。側檔錯誤也不阻斷原有操作比較。

```powershell
.\.venv\Scripts\python.exe scripts/prepare_market_similarity.py --alignment private/d_time_alignment_expanded_20261012/delivery/case_time_alignment_PRIVATE.json --bars private/bars.json --queries private/d_similarity_build_20261012/queries_PRIVATE.csv
```

以上既有清單尚無CONFIRMED，所以預期盤面可用數為0。這是守住證據界線，不是建置失敗。CLI不覆寫已存在輸出；重建前先檢閱並保存舊版，或指定新的私人輸出路徑。

## 介面與聊天

完整池與案例明細分別呈現操作與盤面，距離越低越接近；沒有把距離轉成「相似百分比」或交易信心度。覆蓋率僅表示可比較欄位權重。相對倍數顯示最多3位小數，未知顯示資料不足。

聊天使用相同程式結果及限制，由LLM選擇事實ID，不能自己決定案例、改寫數字或送單。Pages保留合成操作示範，明示盤面未比較，沒有加入私人行情或憑證。本輪未發布GitHub。

## 評測方法

沿用既有30筆按方向／首筆加倉／時間分層的查詢；排除自身候選群。盲評取盈虧分組之前的前5例，隱藏盈虧與方法名稱，避免評分者把賺錢誤認為相似。

每個查詢評：方向／操作是否吻合（0/1）；趨勢是否接近（0/1/2/無資料）；位置是否接近（0/1/2/無資料）；波動是否接近（0/1/2/無資料）；整體可比性（0不相似／1有限／2有參考價值）；說明是否符合數據（0/1/2）；是否應拒絕匹配（是／否／不確定）。先評相關性，再揭露結果，不按盈虧調權重。

沒有盤面證據不能給盤面評分。30筆是小型相關性驗收，不是整體準確率。數量、拒絕率、欄位覆蓋、前5例相關性與重複群比例需分開報告；正反盈虧案例展示測試另外評估。

程式回歸涵蓋未來K棒隔離、價格等比例不變性、無核實證據拒絕、反向大方向排除、缺值懲罰、盈虧不影響排序、過期SHA停用、無效OHLC、聊天引用範圍及既有草稿／成交流程。執行結果另見本輪validation.md；沒有宣稱已完成真人相關性評分。
