# 委託草稿與成交後停損停利

本機新版入口：`http://127.0.0.1:8766/`。本次只改善現有 cTrader DEMO 操作，不新增 LIVE 寫入權限。

## 三種操作的差別

| 操作 | 使用資料 | 結果 | 是否送單 |
| --- | --- | --- | --- |
| 聊天分析做多／做空、比較案例 | 此次盤面快照、該方向歷史案例與可用風險資料 | 所選助手提出理由、條件及案例參照；問句不改原草稿 | 否 |
| 委託欄位選做多／做空 | 目前共用表單 | 只填方向，不額外啟動聊天分析 | 否 |
| 檢查 DEMO 委託 | 已填方向、單型、手數、進場價、停損停利及當時固定盤面 | 程式檢核／試算，所選助手評估這筆草稿；可核對後人工確認 | 檢查本身不送單，另按確認才送 |

模型評估第一段以「這筆委託評估」為主，重點為本筆風險、價位與可調整欄位，不只重複一般多空分析。模型仍只能讀取去識別化事實及占位符，不能計算或改寫金額、判定合法性、確認或送單。舊聊天不改寫。未連模型／失敗時明示錯誤，不冒稱 AI 已分析。

## 取消準備中委託

- 右側與聊天內都有「取消準備中委託」，清除同一份方向、單型、手數、限價、停損停利與交易理由。風險預算偏好保留，聊天紀錄與券商部位不刪。
- 尚未檢查時只是本機清空；已有未送出的檢查草稿時，先呼叫既有 `/api/broker/drafts/{id}/cancel`。成功才清空，失敗保留原欄位與核對內容並顯示原因。
- 草稿版本遞增，取消原草稿助手請求，晚到回覆不能恢復舊草稿或套用舊分析。
- 正在建立／取消／確認，或已送出仍待核對時不允許清空。已接受的掛單不是「準備中草稿」，不能靠此鈕取消；需使用掛單管理流程。已確認回報且帳戶同步後，沿用「準備下一筆委託」。

## 成交後修改停損／停利

右側「帳戶」每筆黃金持倉以卡片呈現，顯示實際帳戶幣別淨損益、原價、現價、停損／停利與操作鈕；原持倉表也保留修改入口。

1. 按「修改停損／停利」，先顯示目前設定。
2. 兩欄各選保留、新增／修改指定價、或移除。指定價預填目前值；保留不傳欄位，移除明確傳 `null`。
3. 「檢查變更」沿用 `/api/broker/positions/{id}/protection-draft`。此時還沒更改券商設定。
4. 人工核對兩個最終價位後按「確認修改停損／停利」，既有後端重新核對原部位、價格、草稿時效、帳戶版本及防重送 key，再送原部位保護修改。
5. `APPLIED` 表示券商回報保護更新，不是新成交；帳戶更新晚於回報才再次開放修改。`UNKNOWN` 等未明結果持續查詢，關閉視窗不丟棄輪詢或開放重送。

無新鮮報價／帳戶、唯讀帳戶不允許修改。移動停損／保證停損仍提示到 cTrader 管理，不以一般價位修改覆蓋。

## 驗證範圍

使用合成券商／助手回應驗證表單、確認、只改單欄、原欄保留、取消失敗、回報未明與同步；未發出真實券商變更或付費模型推論。提示詞測試只能驗證資料與請求格式，不代表實際模型每次措辭一致或交易績效提升。
