# 完整歷史看盤與日期跳轉

進入「歷史回放」，預設為「歷史看盤與日期跳轉」。原來的交易回放仍在「原交易演練」。GitHub Pages保留合成展示；以下功能需下載本機版及本人／授權歷史資料。

## 使用

1. 在查看時間選日期、時分，選台灣時間或UTC，按「跳轉」。圖表時間軸與日期選擇使用同一時區。
2. 切換5分、15分、1小時；圖上以金色圓點標出定位時間。預設聚焦定位點附近約100棒，一次查詢保存600棒，按「全段」可看本次載入範圍。
3. 往圖表左右邊緣拖曳時載入鄰近資料，最多保留2400棒；「更早一段／更晚一段」可繼續翻頁。「最新已保存行情」回到所選來源目前資料上限。
4. 來源預設按日期選擇，可自行選參考行情或本人cTrader DEMO。來源分開呈現，不將兩者拼成同一根K棒。
5. 休市或缺棒會明確提示，沒有補價格或假量。15分及1小時只由完整且連續的五分棒聚合；所選時間沒有完整棒時顯示實際定位時間。
6. 看盤可以看到定位點之後的歷史走勢。它不移動交易演練的模擬時鐘、不更改持倉／草稿，也不會以此時間呼叫即時案例檢索或模型。需交易演練時另切換子頁。

## 資料範圍與更新

作者本機於2026-11-04完成索引：參考行情433,119根M5、本人DEMO 43,573根M5，來源範圍有重疊，不能直接相加稱獨立時點。可用日期起於2020年初，近期資料補取至當天已保存的完整五分棒。這是當次驗收快照，之後以介面實際範圍為準；並非宣稱每個應交易分鐘都齊全。

第一次開啟會背景整理索引（作者資料約12秒），之後依時間索引查一小段；不把多年K棒一次傳入瀏覽器。範圍、來源、量欄位種類與缺口在介面顯示。參考檔的量不是全球成交量，cTrader的量為券商tick量。

有完整授權runtime包時，程式讀取其`reference/bars.csv`；原作者工作區也可從案例特徵檔指向的私人CSV讀取。原始檔案不改寫，快取位於`private/history_library.sqlite`。

要補取較新的本人DEMO行情，在已設定本人`.env.ctrader`的產品目錄執行：

```powershell
# Windows，起點改成介面目前資料上限附近的UTC日期
.\.venv\Scripts\python.exe -m scripts.update_history_library --from 2026-10-29
```

```sh
# macOS
.venv/bin/python -m scripts.update_history_library --from 2026-10-29
```

每次範圍最多400天，可分段執行；同週已完成檔會重用，尚未完整的最後一週會重抓。結果存`private/history_native/`，與案例量能索引分開。腳本只匯入DEMO驗證與歷史行情請求，沒有交易或模型呼叫；錯誤不輸出憑證。下載後會重建看盤索引，介面按「重新整理資料索引」可讀取更新；該按鈕本身只重整本機檔案，不連網下載。

歷史下載依[官方cTrader歷史行情說明](https://help.ctrader.com/open-api/symbol-data/)；請求間隔沿用現有分頁下載器，低於[官方每連線歷史資料限流](https://help.ctrader.com/open-api/)。可取得年份／缺口依本人券商而異，不以其他帳戶快取冒充本人來源。
