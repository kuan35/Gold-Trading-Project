## 使用方式

1. 在交易對話說明多空想法，或於委託區填入方向、單型、手數與選填SL/TP。討論假設仍先分析，不擅改原草稿；按「套用到草稿」才更新欄位。
2. 提問「歷史後續情境與本筆風險」，或按「檢查 DEMO 委託」。回覆保留分析當時的盤面、案例與草稿版本。
3. 「本筆草稿風險」顯示擬進場價、新增手數、停損名目損失。無案例也保留此項。缺券商合約規格或報價未就緒時說明原因，不自行假設合約大小。
4. 「歷史後續與情境損失」可切換5分鐘／30分鐘／1小時及不同展示案例，看到方向調整後期末變動、途中最大逆向／順向，以及同樣走勢對本筆新增草稿的逆向情境損失與SL/TP觸價情況。
5. 按「查看進場前與後續對照」才讀原快照圖表。更改手數或SL/TP後，舊分析會提醒「欄位已變更」；重新提問／檢查產生新快照，舊圖不隨tick變動。

## 計算白話

歷史參考進場有些落在五分棒中間，所以從之後第一根完整五分棒的開盤作為觀察起點。固定看後續1根／6根／12根，不依交易員何時平倉調整窗口。這也表示結果不同於交易員真實成交至真實出場的損益。

買單的最大逆向是觀察起點到期間最低價的下跌；賣單則是起點到最高價的上漲。最大順向反過來算。期末變動也依BUY／SELL方向調整；賣單看到正值代表價格對賣方有利，不表示金價上漲。

草稿情境將歷史每根OHLC除以歷史觀察起點，再乘本筆擬進場價，因此不同年份的絕對金價不會直接照搬。金額由價格差乘本筆手數與券商每手盎司數。這是本筆新增的名目USD，不含既有持倉、價差、佣金、隔夜費、滑價或槓桿資金需求。

最大逆向情境損失是沿完整路徑、未套停損退出的數字。另顯示「停損距離名目損失」與歷史路徑觸價情況，不能把兩者混稱實際停損後的損益。同一根棒同時碰到SL和TP就明示先後未知；跳空超過SL不假設仍可於SL成交。限價全部以「假設已成交後」的情境解讀，不提供成交機率。

## 資料與時間

- 檢索仍只用進場前已收棒，後續資料不參與准入、排序或挑選獲利案例。只加在既有最多五例之後，不冒稱完整匹配池的後續分布。
- 每個固定觀察期必須在當次查詢截止前已完整發生。歷史回放不能看到當時還沒走完的後續。
- 五分棒須連續、每棒觀測分鐘完整、OHLC合法；休市缺口不補棒，無法計算保留原因與null。
- 來源沿現行候選側檔的HistData BID CSV；不是券商真實成交行情。原券商時鐘尚未獨立核實，維持PROJECT_REFERENCE／UNKNOWN。
- 全10,887個已可用參考盤面建置：半小時10,558可用／322缺棒／7分鐘不完整；一小時10,307可用／565缺棒／15分鐘不完整。這不是獨立交易數或相似準確率。
- LLM僅讀去識別化模板、token與程式關係，精確數字本機填回；本輪不實際呼叫外部LLM、不中斷既有人工確認流程。
