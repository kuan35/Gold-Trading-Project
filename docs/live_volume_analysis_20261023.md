# 即時盤面量能解讀

2026-10-23，本機功能；不變更相似案例排序，也未部署公開站。

## 使用方式

開啟本機網站，在交易對話問「五分鐘和一小時的成交量如何？」。可指定五分鐘、十五分鐘、一小時；回覆另列量能區，顯示末根已收棒的券商tick量、相對均量倍率與高於／低於／等於均量。展開「均量與量的定義」可看基準原值。Groq可選啟用；未啟用時程式仍提供相同數值。

## 計算與語義

- cTrader歷史ProtoOATrendbar原生volume是tick量，不是實際成交手數、盎司數或全球黃金成交量。[官方定義](https://help.ctrader.com/open-api/model-messages/#protooatrendbar)。
- 分子是最後一根已收K棒；分母是其前20根已收棒tick量平均，不包含末棒本身。要求最近21根連續且量有效、均量大於0。
- 例如前20根平均100次、最後一根200次，量比2倍，只表示該來源報價較活躍，不推論資金流入或突破有效。
- 末棒真實0且均量正值，量比為0；缺量、缺棒、歷史不足、均量為0均有不同原因，不補0。形成中的棒不參與本次分析。
- 看盤圖形成棒的本機有效Bid接收計數與券商原生完整棒tick量分開，不直接比較。
- 歷史案例側檔缺volume不表示cTrader API沒有歷史量。既有檢索仍不加入量能。

## 模型與快照

量能值與關係由程式計算，與既有行情放在同一分析快照。模型只得到事實模板、代入token和程式關係；數字由後端代入。量能問題優先選量事實，ATR仍是價格波動。缺即時行情或時鐘不通過時不顯示偽即時量。
