# 聊天交易工作台

2026-10-22，本機更新；公開 Pages 沒有部署此輪變更。

首頁是交易對話、共用的準備中委託、持續更新的 cTrader DEMO tick。K 線預設收合。原回放、即時動態三週期圖表、帳戶損益／下單紀錄與平倉入口保留。即時頁的獨立新進場表單改為回到首頁同一份委託，避免兩份草稿繞過未知回報鎖。

## 操作流程

1. 說「我想做多」會查 BUY 案例；沒說方向時只分析盤面，不偷選 BUY。
2. 說「幫我準備做多0.01手市價」，或在對話內／右側點選方向、單型及填入數值，兩處同步。手數／單型／方向未指定就留白；SL／TP 選填。
3. 問「如果改做空呢？」只比較 SELL；BUY 委託保持原值，按「套用到草稿」才改。若在等待期間修改欄位，舊文字解析不可覆寫；舊提案也不可套用。
4. 回答先顯示精簡內容及一小時背景（回答有該依據時），案例只先顯示一組。其餘說明、距離／容忍及歷史分布可展開。沒有通過條件就不塞入近鄰。
5. 「看圖」展開同頁全寬圖表。五分／十五分／一小時各最多90根已收棒；案例四圖維持五分60根／小時20根。固定事件區間、最近6根、已收轉折支撐壓力均由程式標示；可選依據加亮。紫色準備中限價／SL／TP虛線是目前輸入，與固定分析快照分開。
6. 「檢查 DEMO 委託」重新讀當下報價、案例與風險，產生30秒 REVIEW。檢查時改欄位會取消舊 REVIEW，不能確認舊版本。使用者仍須另按「確認送出 DEMO 委託」。聊天 Enter 只送問題。
7. 已接受、部分成交或未知回報持續查狀態，不自動重送；未知狀態保留鎖。成交後等帳戶更新，從「持倉、損益與紀錄」查看。

切換頁面保留本次對話及欄位；重新整理不保留瀏覽器準備中輸入。後端耐久提交日誌另存，未知交易應先核對紀錄，不能因重新整理而重送。

## 資料與解讀

- 相似檢索仍為 context_contract_v1，未調整條件、容忍、成熟時間與排序。通過規則不是人工相似準確率。
- 案例損益是「代表單筆原報表結果」，不是全群合計或已確認含費用淨值。幣別未載照實顯示，未知不補零。歷史分布使用全部通過去重群的代表筆，不只前五組。
- 逐筆結果、case ID、帳號不加入模型事實。Groq 需明確開啟，只組織白話解讀；數字由既有占位符核對並填回。語意仍可能不精確，模型無送單權限。
- 保留報價五秒／來源時鐘領先最多100毫秒且不跨收棒邊界的唯讀檢查，以及券商確認更嚴格的檢查。實測遇到來源時間短暫領先約165毫秒時回資料不足；唯讀對話對同一5分鐘區間內100至250毫秒領先先等本機追上（最多255毫秒），再跑原驗證；超過250毫秒或跨棒不等、不放寬。這不重讀價格、不推進時鐘，也不改送單檢查。
- 自然語言是保守的明確欄位解析，遇到兩方向、相對點數、多個價格或不支援語句會澄清；欄位按鈕是穩定輸入替代。平倉／撤單仍用既有入口。

本輪驗收不確認任何 DEMO 交易。公開站、券商原始時鐘核實與新的相似準確率評估都不屬於此輪完成聲明。
