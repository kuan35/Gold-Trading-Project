## 已定位並修正

1. **非JSON500**：第3至5例程式模板的否定句，被模型自由文字守衛誤擋。可信模板改以fact ID填值、忽略自由輸入；模型數字與引用仍驗證。完整六例池／展示五例的API regression涵蓋此路徑。前端非JSON失敗標示HTTP狀態，保留欄位，不再一律說後端沒啟動；送單不明回報與防重送機制未放寬。
2. **右側隨tick跳動**：每個報價時間戳都取消試算、pending時歸零情境被收成一行。改為同欄位非重疊刷新（完成後一秒），背景更新保留上次數據及展開狀態，標示更新中／暫未完成。新欄位／非CURRENT報價不沿用可執行試算。縮小DOM變動並使用穩定捲軸槽及數字寬度。
3. **核對與Agent矛盾**：檢查草稿先做程式數值檢核，再以同draft/snapshot/as_of評估。聊天與右側共用首個有依據的模型摘要；pending/error/停用/刷新後舊快照均明示，不用另一份程式WAIT冒充。欄位修改或取消時不接收晚到的舊分析。切換聊天取消分析時，同步結束核對區pending，不會永遠顯示正在評估。過期刷新只更新數值，不重跑付費模型，舊解讀明示不適用。
4. **歷史結果未進入摘要**：模型收到同快照盤面、進場前型態、原單進出與全池統計。summary_contract要求首段盤面＋歷史整體數字及有效分母＋案例形態＋支持／反證。可提升已驗證的模型原句，不能替模型杜撰關聯。缺關聯明示INCOMPLETE_HISTORY；COMPLETE只表示引用結構齊全，不是判斷準確率。
5. **模型誤擋與單位**：僅允許指定的否定預測措辭（例如不是這筆草稿的未來勝率），肯定的本次勝率／獲利機率仍拒絕。固定的全池百分比token補足百分號且避免重複，不改數值。簡化草稿提示中的優先順序，首段不要求複誦所有欄位。
