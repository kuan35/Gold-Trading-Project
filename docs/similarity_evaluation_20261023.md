# 相似案例與盤面助手：小型評估協定

本協定在執行前凍結；依使用者同意的先評估、暫不微調模型方案。正式檢索規則、容忍與API保持原樣。

## 相似案例要幫什麼忙

用途是提供可查的歷史參照：相近盤面下，交易員曾怎樣進出、哪些地方和現在不同、後來出現哪些有利或不利情況。這可支持使用者討論想法與檢查風險，不能直接解讀為現在應該買賣、該交易員的真實心理或未來獲利機率。

因此分開驗三件事：案例是否適合拿來比較；助手是否忠於數據、切題且好懂；使用者是否能完成查看／修改／確認前檢查。這輪先完成前兩者的材料與自動管線，人評及實際使用者任務仍須由人執行。

## 檢索試驗

固定種子 `GoldDesk-eval-20261023-v1`，從現有2024–2025完整參考盤面按月份輪流抽30個不同日期，方向盡可能交錯。排除先前51個查詢的日期；同操作群、相同日期與觀察窗口重疊均排除。抽樣僅看時間、方向及完整性，不看損益、檢索排名、事件是否明確或能否匹配。若不足30則直接報錯，不偷偷放寬條件。

依時間前20為本輪開發組、後10為保留評分組；評分前不調規則。資料仍來自曾研究過的歷史來源，這不是全新券商或前瞻獨立樣本，也不是完整市場時點的隨機樣本；查詢源於有交易的時點，不能推廣為所有可進場時機。

每個查詢保留現行context_contract_v1第一名、舊雙路徑第一名，以及同合格池以固定雜湊抽的一個對照。三者若重複只展示一次，解盲鍵記錄全部所屬方法。現行規則零筆就維持零筆，另顯示的舊法／對照不是現行規則通過案例。對照不預設為不像。

盲評頁只呈現匿名編號、相同操作方向與進場前5分鐘60棒／一小時20棒。兩邊各以第一根收盤歸零，同一欄使用相同縱軸；五分圖標出前參考區間與最近六棒，沒有之後的K線。方法／排名／時間／來源／盈虧／自動事件標籤全部遮住；對照順序固定打散。

兩位分開填表：五分走勢與一小時背景各1–5分，事件階段及波動是否接近（same／different／unclear），整體yes／no／insufficient及理由。yes表示「適合拿來比較操作情境」，不是「後續一定同方向」。有明顯事件或背景衝突可填no；看不清或資訊不足填insufficient。評分完成前不要讀解盲檔，也不要討論答案。

摘要分開報各方法有輸出次數、已評分分母、yes/no/insufficient、兩人共同評分數與Cohen kappa。只有非insufficient的有效評分才計yes比例，同時保留insufficient與未填數。無輸出樣本以舊法與固定對照作有限漏檢挑戰；即使沒人認可這兩例，也不能證明整個池沒有相似案例。多人評分是對檢索相關性的評估，不是預測準確率。

## 助手試驗

從上述固定樣本每五個取一個，共六個，不挑模型表現或檢索結果。每題固定相同事實、問題與模型設定，比較程式摘要、現有提示詞、加兩個制式回答範例的提示詞。範例僅示範解釋格式，不傳原始交易ID、帳戶、逐筆損益或金鑰。

樣本是離線參考盤面，回答必須如此標明；不冒稱目前即時價。缺即時報價、新聞、量或指標時明說未提供。外部模型仍僅組織具引用的文字，精確值由原有程式填回。兩種提示詞都維持現有引用／數值驗證，沒有送單權限，沒有微調或學習權重。

最多12次啟用呼叫，兩種提示詞的呼叫先後交錯；任何API非ok狀態都停止並記錄未執行，不因錯誤自動重試。報告分開：API成功、原回答全部通過格式／引用檢查、部分程式補正、退回程式摘要、耗時。這些自動數字不能替代語意正確率。另請兩人對產品最後呈現的回答之忠實、切題及易懂各評1–5分；必須同時保留程式補正／降級來源，不能以補正後好評代表原模型能力。

獨立審查補充：首尾數值保留在本機，但增加程式計算的淨上行／淨下行定性依據，讓模型能回答整段與末段是否一致。這沒有改相似規則。人評分母固定為配對×兩位評分者，刪列／缺交仍計未填；另報前20／後10組與共同有輸出查詢子集，避免拿不同覆蓋率直接比品質。

## 交付與界線

資料、圖、解盲鍵及模型原文只放 `private/similarity_evaluation_20261023/`；公開程式或匿名統計要另依白名單檢查。人評空白不補為no，不由代理替人填分。保留PROJECT_REFERENCE與原始時鐘UNKNOWN；本輪不修改參考時間模型，也不做獲利回測。若未完成評分，成果只能稱「評估工具與材料已準備」，不能稱已證實準確。
