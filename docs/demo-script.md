# 展示腳本

建議先按重設，回到一致的回放起點。這會清空本機展示持倉。

1. 介紹中央 K 線、右側下單及下方持倉，指出回放時間、來源、非即時行情。
2. BUY 0.10 手、不設定停損。送出草稿，說明尚未成交，指定價格下跌的情境不是損失上限。
3. 查看完整匹配池，再開一個虧損案例，指出時區未確認與目前尚未提供案例 K 線。
4. 取消一次草稿，證明不會留下持倉；重新建立並確認一次。
5. 以相同方向加倉 0.10 手，比較新增前後總手數與整組情境損失；均價變動不保證風險降低。
6. 推進一根 K 棒，查看首筆與加倉標記；確認平倉其中一筆，查看損益和成交紀錄。
7. 輸入「買進黃金0.05手」，證明對話與表單共用草稿；取消它，不讓助手自行成交。
8. 查看資料分群，介紹來源觀察列、重複與順序不明限制。公開版本是合成資料，私人本機才是交易員資料。
9. 切到券商模擬模式，展示未連線狀態，說明還需要帳戶授權與真實成交回報測試。
10. 展示手機與淺色介面；最後介紹報告中的時區對齊、API、MAE、警示和多人使用擴充。

展示目標是看懂部位與資訊限制、完成可追溯操作，不以本機盈虧作獲利能力證據。
