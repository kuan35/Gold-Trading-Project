# 聊天閱讀與資訊分層

2026-10-23，依使用者最新要求更新本機首頁。此要求取代上一版「聊天區無內層捲動」的設計；整頁仍可捲動，聊天紀錄改為獨立有界捲動。

## 介面

- 聊天紀錄固定高度，依視窗高度調整，訊息與展開明細只增加區內捲動內容，不推長工作台。輸入框在聊天紀錄下方，未置於紀錄捲動區。
- 新提問定位該輪開頭；手動翻舊訊息時不強制跟隨回覆，使用「回到最新對話」可返回。定位僅操作紀錄scrollport，沒有使用對話的scrollIntoView拉動整頁。圖表按需開啟仍沿用原同頁流程。
- 主要回答與使用者訊息17px，窄版16px；欄位與次要資訊亦放大。長段先顯示四行，有明確展開按鈕；全文及原始數據仍可查看。
- 預設至多兩段盤面重點、一組案例的方向／事件／代表單筆結果。問支撐壓力就優先顯示程式參考價，問動能或波動優先相應資料，不再固定只貼趨勢。既有原值、案例排序及結果語義不改。
- 案例相似原因、數值差距、歷史分布及完整回覆收在「詳細依據」；一般方法、資料時點、幣別／歷史結果、模型資料範圍移到工作台下方Q&A。操作明細的一般限制另收合，缺漏與截斷等案例特定狀態仍直接顯示。圖表說明亦改為按需展開。
- 行情不足／斷線、欄位修改與歧義、委託拒絕／UNKNOWN等當下需處理的狀態不隱藏。Groq與程式來源維持標籤區分，不重複插入制式解釋。
