# 對帳單時間戳與進出場 K 線：候選定位實測

**可以先依對帳單時間找進、出場相對位置。** 對帳單的日期時間未附可核實的 UTC 偏移，因此做法是為每個來源套用其價格推定的時鐘假說，把同一筆進場與平倉時間一起轉到參考行情，找各自所屬的 5 分鐘棒。價格與參考 BID 棒的高低區間差距只是診斷；不同券商、BID／ASK 與執行價不會完全相同，不把價差當成剔除條件。

2021–2025 年 7,331 筆產品候選逐筆檢查結果：

| 條件式結果 | 筆數 |
| --- | ---: |
| 同時找到進場與平倉參考棒 | 7,110 |
| 進場在夏令邊界，保留多個可能時鐘 | 171 |
| 平倉在夏令邊界，未指定單一平倉棒 | 47 |
| 進或出場的參考棒缺失 | 2 |
| 平倉 UTC 假說缺失 | 1 |

在 7,110 個可定位配對中，7,035 筆的進、出場價都落在對應 BID 5 分鐘棒高低區間 ±0.5 美元內；有 35 筆至少一端差距超過 2 美元，**仍保留其候選標記**。這是價格選模後在同系行情快取上的回看相容性，不能解讀為 7,035 筆時間正確。5 分鐘棒也只代表所屬區間，不能精確還原棒內成交秒數與執行報價。

為檢查「兩個價都吻合就能唯一找回時鐘」，把進、出場標記**同時**平移前後一小時，保留原持倉時間。在原位置與兩種位移位置都有棒的 6,379 筆中，原位置有 6,316 筆雙價格落入 ±0.5 美元；其中 1,100 筆在至少一個位移位置也同樣吻合。這僅檢查前後一小時，不是所有可能時區的排他性測試；但足以顯示單筆進出場價不能總是選出唯一時鐘。同一來源跨多日一致性及夏令切換週可以再縮小歧義。

實務上應分清兩個結論：

1. **候選進出場定位**：有來源級時鐘假說、進出場時間先後合理、兩個參考棒存在，就能在歷史回看圖上標示「推定位置」，並顯示原始時間、推定 UTC、參考報價差距及來源。這輪已對 7,110 筆做到私人離線配對。
2. **已核實的歷史盤面**：要將這些圖用於正式案例 K 線／盤面相似度，仍需把原匯出與帳戶的歷史時鐘、夏令規則及參考行情 UTC 時鐘連上可追溯證據，並在未參與選模的日期驗證。完成前保持 `UNKNOWN`、`production_enabled=false`。

平倉價可以用來**回頭核對已結束交易的定位**，不能用來挑選進場前相似案例的 K 線或特徵，否則會把未來資訊帶入檢索。私人逐案標記、價差與未解原因保存在 `product/private/price_only_probe_20261013/paired_entry_exit_markers_PRIVATE.json`；公開報告只含彙總。
