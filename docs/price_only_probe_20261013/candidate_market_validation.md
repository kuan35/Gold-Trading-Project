# 候選盤面檢索與三週期補全驗證（2026-10-16）

這是本機候選檢索的資料覆蓋稽核，不是交易時間正確性證明，也不是相似度準確率。逐筆來源、候選時刻、K 線與盲測案例 ID 僅保留於 `product/private/`。

| 固定母體 | 數量 | 意義 |
| --- | ---: | --- |
| 產品可用候選 | 11,902 | 不是去重後的獨立決策數 |
| 可建立事前盤面特徵 | 10,921 | 全部是時鐘未核實的候選；完整三週期 6,573，其餘 4,348 僅五分鐘 |
| 正式確認盤面 | 0 | 券商伺服器時區仍待逐帳戶核實 |
| 此輪指定補全母體 | 4,971 | 2,577 完整三週期；2,381 五分鐘限定；13 策略邊界差異未納入 |

指定的 4,971 筆中，2,344 筆高週期窗口有無法解釋的缺口，37 筆有跨來源小時 K 線衝突；這兩類保留五分鐘層，不補造缺失 K 線。另有 285 個排程形態且兩份行情快取都顯示缺席的候選休市區間，用於候選高週期連續性判斷；它們不能證明每年的歷史交易時鐘與券商帳單一致。所有案例維持 `timezone_status=UNKNOWN`、`production_enabled=false`。

檢索先限定同方向及查詢前已成熟案例，排除同一候選操作群重複展示。五分鐘 K 線形狀以 ATR 正規化；技術指標使用已收盤 5 分、15 分與 1 小時 K 線。形狀與指標各自算同層候選池相對排名，依兩軸較差者排序。手數、首筆或加倉、事後盈虧、平倉價不參與相似度。完整與五分鐘限定層不跨層比分數；目前沒有經盲評校準的「足夠相似」門檻。歷史獲利比例只描述已形成的候選池。

盲測封包固定 2024–2025 年每個具完整特徵的月份首個查詢，共 21 個月份；方向列表、僅 K 線形狀、僅技術指標、雙軸四種方法都在 21／21 個查詢有候選。查詢自身操作群與當時尚未成熟案例排除；零候選查詢仍會留在分母。封包未附盈虧給評分者，尚無人工形狀／趨勢／波動相關性判斷，因此**不能**說雙軸勝過基線，也不能據此調權重或宣稱預測勝率。下一個實證步驟是先收盲評，再比較四法的前五名相關性、覆蓋率與來源分層，最後才討論拒絕門檻。
