# 2021–2025 歷史案例的來源時鐘補證優先序

這是離線診斷，不是已確認的歷史 K 線配對。產品候選 7,331 筆中，先前有 3,849 筆在**價格推定的 UTC 假說**下可取得進場前候選盤面；另 2,960 筆沒有唯一 UTC 假說。本輪針對後者的 29 個來源，估計若其來源時鐘日後獲得原生證據支持，現有快取行情可以提供多少候選盤面。正式時間確認及正式歷史盤面配對仍皆為 **0**，`production_enabled=false`。

| 2,960 筆未定案例的條件式結果 | 筆數 |
| --- | ---: |
| 5 分、15 分、1 小時進場前候選盤面 | 1,393 |
| 僅有足夠的 5 分進場前候選盤面 | 1,058 |
| 5 分上下文不足 | 338 |
| 美歐夏令切換邊界，保守排除單一盤面 | 171 |

前兩項合計 **2,451 筆條件式可取圖**，代表按各來源既有價格選模假說計算的行情覆蓋量，並不代表 2,451 筆已對上正確時間。若把它與先前的 3,849 筆候選相加，2021–2025 在這組假說下合計 6,300／7,331 筆可檢視候選盤面；兩組都未獲正式時鐘確認，不能用在正式盤面相似度。不同時鐘假說也可能改變行情覆蓋，因此 6,300 不是已證實的理論上限。

若按條件式可取圖數排序，前 3 個來源涵蓋 1,296 筆未定案例、其中 1,079 筆條件式可取圖；前 10 個來源涵蓋 2,355 筆未定案例、其中 1,978 筆條件式可取圖。這能把補證工作集中在少數**來源**，無須請交易員逐筆重標。私人原件名與逐案結果只存於 `product/private/price_only_probe_20261013/`，未列在本公開報告。

重新掃描這 29 個原始匯出（15 CSV、9 XLSX、5 HTML），未在 CSV 欄名或匯出文字找到明確時區／伺服器時間標籤，也未找到 UTC／GMT 偏移字串；5 個 HTML 含「帳戶號碼」字樣，但這不是歷史匯出時鐘證據。15 份 CSV 均有非空 `Ticket` 欄，前 10 優先來源中占 9 份；其值尚未核實為原平台訂單 ID。此為文字與工作簿 XML 的有限掃描，不能證明原平台沒有設定。另有 5 個來源在既有稽核中帶券商標頭、13 個來源有跨格式可見交易的經濟欄位橋接；這些都沒有確認同一原生帳戶身份或匯出時鐘。

下一步按私人優先清單逐來源取得可核對的原生帳戶／伺服器識別、匯出時間設定，以及一筆含原生訂單 ID 的橋接紀錄，並查該帳戶對應年份的券商 UTC 偏移及夏令切換。專案端還要取得可追溯的原始 UTC 行情時間回應，再用未參與選模的日期複核。2026-10-16 限量重試公開 tick 端點時，直接請求收到 HTTP 429 並立即停止，仍為 0 個原始檔／0 根原始 K 棒；沒有切換端點規避限流。任何一步未完成時保留 `UNKNOWN`；價格趨勢或指標相似、文字 RAG 都不能反推出正確歷史 UTC。

可重跑腳本為 `source_clock_priority.py`、`source_clock_native_scan.py`，驗證為 `validate_source_clock_priority.py`；私人逐案情境及補證清單與公開報告分離。現有兩份價格快取高度同源，不能視為兩票獨立行情證據。
