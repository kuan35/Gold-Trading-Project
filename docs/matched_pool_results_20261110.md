# 背景回答與全部匹配案例的歷史結果

## 回答期間的操作

AI的唯讀回答不再鎖定整個工作台。可切換主頁／聊天、查看圖表、編輯草稿或模型設定。每段聊天最多一個一般回答請求，切到別段可另提問；每個請求固定原聊天、模型選擇、對話脈絡與委託欄位版本。回覆寫回原對話，背景完成時一併保存原對話，不能套用到目前別段聊天。

解析期間若切換聊天或修改欄位，晚到的自然語言修改不能自動改目前草稿。刪除聊天會中止其前端請求並拒收晚到結果，避免聊天復活；可按「停止回覆」中止當前等待。交易核對與送出未明時的鎖定、防重送與人工確認保持原流程。

## 歷史統計母體

先完成原有同方向、成熟、不重疊、事件／路徑／波動／tick條件，再依原排序做群及盤面時點去重。對全部留下的案例，每群只取排序選中的一筆代表原單，先算統計，再截取最多五例展示。開關獲利／虧損或改看哪例，都不改整個匹配池的分母。

新增 `original_performance`，透過固定快照的 `case_comparison.performance` 與 `history.aggregate` 提供介面和Agent，包含：

- 總案例數、報表損益有效數、獲利／虧損／損益為零／未知數。
- 歷史獲利比例 = 獲利代表單數 ÷ 有效報表損益代表單數；零損益在分母、未知損益不在分母，同時保留完整池總數。
- 平均價格報酬 = 各有效原單「方向調整價差 ÷ 進場價 ×100」的算術平均，未扣交易成本；不是保證金報酬。
- 平均每盎司價差 = 原單方向調整價差的平均，避免手數大小改變價格尺度。
- 平均單筆原報表損益，分已載明的幣別計算；另列獲利單平均、虧損單平均。金額保留原手數差異，不是標準化策略獲利。

缺值不補零；幣別未載不合併金額；不同幣別不相加或假設匯率。每個平均各列自己的有效數。只代表已匹配原單的歷史表現，候選群不保證獨立交易決策，也不當作目前交易獲利機率。

摘要預設顯示整體結果，不用第一例的報酬代替平均。模型同樣取得全池結果的占位符與定性狀態，精確值在本機填回；原始交易數值不因這次改版新增外傳。

## 點開個案

比較圖每次選取案例都顯示該原單的進場／平倉日期與時間。每例的操作明細也附原單及可見序列各自的時間。來源缺時間就明示未提供，不從群代表單繼承。

原單時間保持對帳單記載，不換成圖表UTC或電腦時區；圖表參考時間與原單時間分開顯示。兩者仍受原始時鐘未獨立核實的既有界線約束。

## 額外修正與驗證

方向原因的均線名稱先依其自己的週期換算，避免五分K的MA20被同一段的一小時引用誤換成20小時。

回歸包含全部六例、畫面只展示五例時仍以六例平均；多幣別及未知值；模型停用時的統計模板；每例時間切換；回答期間跨頁／並行對話／停止／刪除及延遲草稿解析。使用合成模型與攔截API，不做真實送單或付費推論。
